# 🍒 Portfolio — Carol Daga

Portfolio pessoal de Carol Daga, UI/UX Designer e Desenvolvedora Frontend.

## 🔗 Acesse

> Deploy via GitHub Pages, Vercel ou Netlify.

---

## 📁 Estrutura
portfolio/
├── index.html       # Estrutura principal da página
├── style.css        # Estilos e responsividade
├── script.js        # Lógica: formulário, carousel, animações
└── README.md
---

## ✨ Funcionalidades

- **Hero animado** com cereja 3D em Canvas e efeito de parallax com o mouse
- **Cursor customizado** com anel de rastreamento suave
- **Carousel de projetos** com navegação por botões, dots e auto-avanço
- **Skills** com barras de progresso animadas por scroll
- **Timeline de experiência** profissional
- **Formulário de contato** integrado ao Formspree
- **Menu hambúrguer** responsivo com animação e overlay
- **Scroll fade-in** em todas as seções

---

## 🛠️ Tecnologias

- HTML5 + CSS3 (puro, sem frameworks)
- JavaScript (Vanilla)
- Canvas API
- [Formspree](https://formspree.io) — envio de formulário
